# validation/protocols/ — 確かめる手順

実機・台の上で確かめる手順を、版つきで 1 か所に置きます。検証の記録は `protocol: { id, version }` でここを指します。

```
validation/protocols/<手順の ID>.md     例: SMOKE.md
```

- 先頭に手順の ID と版を書きます（例: `# SMOKE（版 1）`）。中身を変えたら版を上げ、前の版で確かめた記録はそのまま残します
- 項目ごとに ID（例: `C1`）を付け、検証の記録の `cases` の ID と合わせます
- 値（IP・製造番号・閾値の値）は書きません。案件の設定を指すときは道だけを書きます
