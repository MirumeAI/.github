# evaluation/ — 固定した評価の結果

**同じデータで測った結果**を残します。

- 評価データの版（`manifests/` を参照）
- 未検出・過検出の件数
- 面ごとの内訳
- この案件で値を選んだ記録（選んだ値・根拠の数・測ったデータの版〔manifest の sha256〕）。判定側の設定とそろえた形は `MirumeAI/development-docs` #273 で決めます

`evaluation/` は顧客の間の混入の検査が照らしません。ほかの案件の値・IP・製造番号を置きません。秘密・資格情報・顧客データは、どの案件のものも置きません（Private でも同じ）。記録の Pull Request は人が中身を見て確かめます。

## 置かないもの

- 毎回変わるデータでの結果（比較にならない）
- 画像・モデルの本体（`manifests/` に参照と hash だけを置く）

**評価データを変えたら、それまでの数字と比べられません。** 変える場合は版を上げ、どちらの版で測ったかを必ず書きます。
